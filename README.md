# KIZUNA

### Intelligent Railway Maintenance Coordination

## Overview

**KIZUNA** is a railway maintenance coordination project that explores how intelligent scheduling can improve maintenance planning across multiple railway departments.

The project uses an **A/B simulation approach** to compare traditional decentralized maintenance planning with a more coordinated, optimization-driven approach.

---

## Problem Statement

Independent maintenance planning can lead to:

* Repeated maintenance blocks
* Increased infrastructure downtime
* Higher train delay minutes
* Inefficient coordination between departments

**KIZUNA aims to explore a more coordinated and data-driven solution.**

---

## Approach

| Traditional Approach                  | KIZUNA Approach               |
| ------------------------------------- | ----------------------------- |
| Independent planning                  | Coordinated planning          |
| Separate maintenance blocks           | Optimized maintenance windows |
| Limited cross-department coordination | Integrated task evaluation    |
| Higher operational disruption         | Focus on reducing disruption  |

---

## Key Focus Areas

| Area                     | Description                                        |
| ------------------------ | -------------------------------------------------- |
| **Simulation**           | A/B comparison of different planning approaches    |
| **Maintenance Planning** | Evaluating and prioritizing maintenance activities |
| **Optimization**         | Identifying efficient maintenance windows          |
| **Operations**           | Measuring impact on downtime and train delays      |

---

## Metrics

The project evaluates performance using:

| Metric                          | Purpose                               |
| ------------------------------- | ------------------------------------- |
| **Asset Downtime**              | Measure infrastructure unavailability |
| **Train Delay Minutes**         | Measure operational disruption        |
| **Maintenance Completion Rate** | Measure maintenance effectiveness     |
